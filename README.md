# 🕶️ Google Glass Website

> Projeto interativo sobre o Google Glass, desenvolvido durante os estudos de HTML5 e CSS3 pelo **Curso em Vídeo**, com adaptações e melhorias autorais de estrutura e estilo.

---

## 📌 Sobre o Projeto

Este site é uma releitura do projeto clássico do **Google Glass**, apresentado originalmente pelo professor Gustavo Guanabara no [Curso em Vídeo](https://www.cursoemvideo.com/). 

Embora baseado na proposta original do curso, o projeto foi **customizado e reestruturado**, aplicando decisões de design próprias, novas escolhas de estilização e uma organização de código aprimorada para praticar conceitos de desenvolvimento web.

---

## ✨ Diferenciais e Adaptações Pessoais

Para ir além do conteúdo das aulas, foram implementadas as seguintes alterações:

* **Arquitetura de Código:** Organização de pastas e arquivos refinada para facilitar a manutenção.
* **HTML5 Semântico:** Ajustes na estrutura de tags para priorizar a acessibilidade e boas práticas.
* **Estilização Autoral (CSS3):** Modificações na paleta de cores, tipografia, espaçamentos e efeitos visuais.
* **Ajustes de Layout:** Melhorias pontuais na disposição dos elementos e na usabilidade da página.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, efeitos e design do site.
* **JavaScript:** Interações como troca de fotos ou áudio.
